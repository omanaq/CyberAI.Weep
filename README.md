# CyberAI OS - مشروع الذكاء الاصطناعي المحلي

## مقدمة
CyberAI OS هو مشروع مفتوح المصدر يتيح لك تشغيل نماذج الذكاء الاصطناعي محليًا دون الحاجة إلى مفاتيح API أو اتصال دائم بالإنترنت.

## مميزات المشروع
- تشغيل محلي 100%
- دعم نموذج Mistral 7B
- واجهة دردشة بسيطة ومتقدمة
- دعم FastAPI
- إعداد مرن على Termux / Debian
- توثيق شامل للواجهات والخصائص

---

### index.html - الصفحة الرئيسية
تحتوي على مقدمة المشروع، وشعار، وزرين رئيسيين للتنقل إلى دليل الإعداد أو تجربة المحادثة.

---

### setup-guide.html - دليل الإعداد
يوفر تعليمات كاملة لتثبيت المشروع على أنظمة Android وLinux وWindows.

---

### chat-interface.html - واجهة دردشة بسيطة
نموذج واجهة لإرسال واستقبال الرسائل مع النموذج بطريقة مباشرة.

---

### chat-interface-advanced.html - واجهة دردشة متقدمة
تتضمن إعدادات إضافية مثل temperature وtop_p وعدد الرموز.

---

### api-key-management.html - إدارة مفاتيح API
واجهة بسيطة لإدخال وإدارة مفاتيح واجهة برمجة التطبيقات.

---

### api-server.html - خادم API
صفحة توضح كيفية تشغيل واجهة برمجة التطبيقات عبر FastAPI، وتوثيق المسارات.

---

### about.html - من نحن
صفحة تعريفية بالمشروع وصاحبه.

---

### contact.html - اتصل بنا
نموذج تواصل بسيط لجمع استفسارات المستخدم.

---

### local-models.html - النماذج المحلية
تعرض النماذج المدعومة للتشغيل المحلي، مثل Mistral وTinyLlama.

---

### model-manager.html - إدارة النماذج
صفحة لإدارة النماذج التي تم تحميلها وتحديثها.

---

### tools.html - أدوات مساعدة
أوامر وأدوات إضافية مساعدة لتشغيل المشروع.
