## 🚀 المميزات الرئيسية

- **التشغيل المحلي** (Offline-First Design)
- دعم نماذج **Mistral 7B** و **TinyLlama**
- تكامل أمان مع **OAuth 2.0**
- واجهة مستخدم تفاعلية مع Dark Mode
- نظام إدارة سياقات متقدم
- دعم كامل للغة العربية
