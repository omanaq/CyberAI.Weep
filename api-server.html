خادم API للنماذج المحلية

يوفر خادم API واجهة برمجية متوافقة مع OpenAI للتفاعل مع نماذج الذكاء الاصطناعي المحلية. يمكنك استخدام هذه الواجهة لدمج النماذج المحلية في تطبيقاتك.

بدء تشغيل خادم API

لتشغيل خادم API المحلي، اتبع الخطوات التالية:

  1. تأكد من تثبيت llama-cpp-python كما هو موضح في دليل الإعداد
  2. قم بتشغيل الخادم باستخدام الأمر التالي:
python -m llama_cpp.server --model path/to/model.gguf --host 127.0.0.1 --port 8000

بعد تشغيل الخادم، يمكنك الوصول إلى واجهة API على العنوان: http://127.0.0.1:8000/

نقاط النهاية (Endpoints)

يوفر خادم API النقاط التالية:

POST /v1/completions

إنشاء إكمال نصي للنص المعطى.

معلمات الطلب:

المعلمة النوع الوصف
مطلوب prompt string النص المراد إكماله
اختياري max_tokens integer الحد الأقصى لعدد الرموز في الإكمال (الافتراضي: 16)
اختياري temperature number درجة العشوائية في الإكمال (0-2، الافتراضي: 0.8)
اختياري top_p number احتمالية النواة المستخدمة في أخذ العينات (0-1، الافتراضي: 0.95)

مثال على الطلب:

{
  "prompt": "مرحباً، كيف حالك؟",
  "max_tokens": 512,
  "temperature": 0.7,
  "top_p": 0.9
}

إرسال طلب إلى /v1/completions

دمج API في تطبيقاتك

يمكنك دمج واجهة API المحلية في تطبيقاتك باستخدام أي لغة برمجة تدعم طلبات HTTP. إليك بعض الأمثلة:

JavaScript (Fetch API):

async function generateCompletion(prompt) {
  const response = await fetch('http://localhost:8000/v1/completions', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({
      prompt: prompt,
      max_tokens: 512,
      temperature: 0.7,
    }),
  });
  
  const data = await response.json();
  return data.choices[0].text;
}

// استخدام الدالة
generateCompletion('مرحباً، كيف حالك؟')
  .then(text => console.log(text))
  .catch(error => console.error('Error:', error));

Python (Requests):

import requests

def generate_completion(prompt):
    response = requests.post(
        'http://localhost:8000/v1/completions',
        json={
            'prompt': prompt,
            'max_tokens': 512,
            'temperature': 0.7,
        }
    )
    data = response.json()
    return data['choices'][0]['text']

# استخدام الدالة
text = generate_completion('مرحباً، كيف حالك؟')
print(text)
