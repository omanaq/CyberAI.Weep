متطلبات النظام لـ Windows

الحد الأدنى:

  • نظام Windows 10 أو أحدث (64 بت)
  • ذاكرة RAM: 8GB على الأقل (16GB موصى به)
  • معالج حديث متعدد النواة
  • مساحة تخزين: 2GB على الأقل للبرامج والنماذج الصغيرة

تثبيت llama.cpp

llama.cpp هو برنامج خفيف لتشغيل نماذج اللغة المحلية. يمكنك تثبيته بإحدى الطرق التالية:

الطريقة 1: تنزيل الإصدار المجمع مسبقًا

  1. قم بزيارة صفحة الإصدارات
  2. قم بتنزيل أحدث إصدار لنظام Windows (ملف zip)
  3. قم بفك ضغط الملف في مجلد على جهازك

الطريقة 2: البناء من المصدر

إذا كنت تفضل بناء البرنامج من المصدر، اتبع الخطوات التالية:

> git clone https://github.com/ggerganov/llama.cpp
> cd llama.cpp
> mkdir build
> cd build
> cmake ..
> cmake --build . --config Release

تنزيل وتشغيل نموذج TinyLlama

TinyLlama هو نموذج خفيف مثالي للأجهزة محدودة الموارد:

تنزيل النموذج:

> curl -L -o tinyllama.gguf https://huggingface.co/TheBloke/TinyLlama-1.1B-Chat-v1.0-GGUF/resolve/main/tinyllama-1.1b-chat-v1.0.Q4_K_M.gguf

أو يمكنك تنزيله مباشرة من هنا

تشغيل النموذج:

> cd path\to\llama.cpp
> .\build\bin\Release\main.exe -m path\to\tinyllama.gguf -c 512 -p "مرحبا، كيف حالك؟"

تنزيل وتشغيل نموذج Llama 2

Llama 2 هو نموذج متوسط الحجم مع أداء متوازن:

تنزيل النموذج:

> curl -L -o llama2.gguf https://huggingface.co/TheBloke/Llama-2-7B-Chat-GGUF/resolve/main/llama-2-7b-chat.Q4_K_M.gguf

أو يمكنك تنزيله مباشرة من هنا

تشغيل النموذج:

> cd path\to\llama.cpp
> .\build\bin\Release\main.exe -m path\to\llama2.gguf -c 2048 -p "مرحبا، كيف يمكنني استخدام الذكاء الاصطناعي في مشروعي؟"

إعداد واجهة API (اختياري)

يمكنك تشغيل خادم API محلي لاستخدام النموذج في تطبيقاتك:

تثبيت Python:

تأكد من تثبيت Python 3.8 أو أحدث من هنا

تثبيت llama-cpp-python:

> pip install llama-cpp-python[server]

تشغيل خادم API:

> python -m llama_cpp.server --model path\to\tinyllama.gguf --host 127.0.0.1 --port 8000

يمكنك الآن الوصول إلى واجهة API على العنوان: http://127.0.0.1:8000/

متطلبات النظام لـ Linux

الحد الأدنى:

  • توزيعة Linux حديثة (Ubuntu 20.04+, Debian 11+, Fedora 35+)
  • ذاكرة RAM: 8GB على الأقل (16GB موصى به)
  • معالج حديث متعدد النواة
  • مساحة تخزين: 2GB على الأقل للبرامج والنماذج الصغيرة

تثبيت المتطلبات الأساسية

$ sudo apt update && sudo apt install -y build-essential cmake git python3-pip

تثبيت llama.cpp

$ git clone https://github.com/ggerganov/llama.cpp
$ cd llama.cpp
$ mkdir build && cd build
$ cmake ..
$ make -j4

تنزيل وتشغيل نموذج TinyLlama

$ wget -O tinyllama.gguf https://huggingface.co/TheBloke/TinyLlama-1.1B-Chat-v1.0-GGUF/resolve/main/tinyllama-1.1b-chat-v1.0.Q4_K_M.gguf
$ ./build/bin/main -m tinyllama.gguf -c 512 -p "مرحبا، كيف حالك؟"

إعداد واجهة API (اختياري)

$ pip3 install llama-cpp-python[server]
$ python3 -m llama_cpp.server --model tinyllama.gguf --host 127.0.0.1 --port 8000

الحد الأدنى:

  • macOS 11 (Big Sur) أو أحدث
  • ذاكرة RAM: 8GB على الأقل (16GB موصى به)
  • معالج Intel أو Apple Silicon
  • مساحة تخزين: 2GB على الأقل للبرامج والنماذج الصغيرة

متطلبات النظام لـ Android

الحد الأدنى:

  • Android 8.0 أو أحدث
  • ذاكرة RAM: 6GB على الأقل
  • معالج حديث (Snapdragon 8xx أو ما يعادله)
  • مساحة تخزين: 1GB على الأقل للتطبيق والنماذج الصغيرة

تثبيت تطبيق MLC LLM

MLC LLM هو تطبيق يتيح تشغيل نماذج اللغة على الأجهزة المحمولة:

  1. قم بتنزيل تطبيق MLC LLM من متجر Google Play
  2. افتح التطبيق واتبع التعليمات لتنزيل نموذج TinyLlama أو أي نموذج آخر خفيف
  3. يمكنك الآن استخدام النموذج للدردشة مباشرة على هاتفك

تثبيت تطبيق LLM Studio (بديل)

LLM Studio هو تطبيق آخر يدعم تشغيل نماذج GGUF على الأجهزة المحمولة:

  1. قم بتنزيل تطبيق LLM Studio من متجر Google Play
  2. افتح التطبيق وانتقل إلى قسم "النماذج"
  3. اختر نموذج TinyLlama أو أي نموذج آخر خفيف للتنزيل
  4. بعد التنزيل، يمكنك بدء الدردشة مع النموذج

نصائح لتحسين الأداء على الأجهزة المحمولة

  • استخدم نماذج مكممة بشكل كبير (Q2_K أو Q3_K_S) للحصول على أداء أفضل
  • قم بإغلاق التطبيقات الأخرى قبل تشغيل نماذج الذكاء الاصطناعي
  • تأكد من توفر مساحة كافية على جهازك
  • استخدم الشاحن أثناء تشغيل النماذج لتجنب استنزاف البطارية

استكشاف الأخطاء وإصلاحها

إذا واجهت مشاكل أثناء الإعداد، جرب الحلول التالية:

  • خطأ "Out of memory": استخدم نموذجًا أصغر أو نسخة مكممة بشكل أكبر
  • بطء في الاستجابة: قلل قيمة المعلمة -c (سياق النموذج) أو استخدم نموذجًا أصغر
  • مشاكل في تثبيت llama-cpp-python: تأكد من تثبيت أدوات البناء المناسبة لنظامك
  • أخطاء في تشغيل النموذج: تأكد من استخدام المسار الصحيح للنموذج ومن تنزيله بشكل كامل
